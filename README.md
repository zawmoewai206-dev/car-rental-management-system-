# Car Rental Management System

Java・Hibernate・Maven・MySQLを使用して開発したレンタカー管理システムです。

## 使用技術

- Java
- Maven
- Hibernate
- MySQL

## 主な機能

- 顧客情報の管理
- 車両情報の管理
- レンタル情報の管理
- メンテナンス情報の管理
- 返却期限超過時の延滞料金計算

## 担当

5人チームで開発し、リーダーとして開発を進めました。
主に顧客管理機能を担当しました。

## Database

MySQLを使用しています。

### Tables

- Customer
- Car
- Rent
- Maintenance
